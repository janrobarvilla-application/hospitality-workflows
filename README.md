# hospitality-workflows
Documentation of end-to-end workflows used in group sales coordination, reservations, and operations. These workflows demonstrate structured thinking, async communication habits, and process clarity.
# End-to-End Group Booking Workflow

## 1. Lead Intake
- Review inquiry details  
- Identify group needs  
- Log lead in PMS / CRM  
- Coordinate with Sales for initial proposal  

## 2. Contracting & Room Block Setup
- Encode room block in PMS  
- Assign market codes  
- Add billing instructions  
- Confirm cutoff dates  

## 3. Pre-Arrival Coordination
- Create Group Resume  
- Share with Operations, Front Office, Housekeeping, F&B  
- Collect rooming list  
- Confirm special requests  

## 4. Stay Execution
- Monitor arrivals  
- Support operational teams  
- Update rooming list changes  
- Communicate adjustments  

## 5. Post-Stay
- Prepare final billing  
- Reconcile charges  
- Issue invoice  
- Respond to post-event inquiries  

---

This workflow highlights how I manage complex coordination across departments using clear documentation and async communication.
